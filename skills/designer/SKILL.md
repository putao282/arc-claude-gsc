# designer (UX-UI)

Use this skill at the start of the **pages** STEP — BEFORE editing or creating UI.

## Required actions
1. Load this skill first (Skill tool), then design pages/components.
2. Prefer clear accessible names, stable layout, and requirement-aligned controls.
3. Implement under `frontend/src/pages` and/or `frontend/src/components`.
4. Record UI artifacts in `.arc/steps/<module-id>/pages.json`.

## Exit
Harness acceptance requires this skill load proof plus UI/page file artifacts.
